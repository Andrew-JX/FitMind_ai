# FitMind AI — UI 规格文档（UI_SPEC.md）

> 每次开始写前端组件前必须读这份文档。
> 颜色 token、组件结构、交互逻辑以此为准，不得自行发明。

---

## 1. 设计原则

- **风格参考**：训记 App（国内健身日志应用）—— 硬核、极简、数据驱动
- **主色调**：夜间优先，荧光黄绿（`#c8f035`）作为强调色
- **信息密度**：高密度，训练数据优先展示，减少装饰性元素
- **圆角风格**：卡片 14px，按钮 12-14px，输入框 10-12px，胶囊标签 20px
- **字体**：`-apple-system, 'PingFang SC', 'Helvetica Neue', sans-serif`
- **移动端优先**：最大宽度 390px，所有布局以竖屏手机为基准

## 2. 颜色 Token

### 2.1 夜间模式（默认）

```ts
// tokens/colors.dark.ts
export const dark = {
  bg:      '#0f0f0f',   // 页面背景
  surf:    '#1a1a1a',   // 卡片/弹窗背景
  surf2:   '#222222',   // 次级表面（输入框、统计格子背景）
  surf3:   '#2c2c2c',   // 三级表面（已完成组、tag背景）
  bdr:     'rgba(255,255,255,0.08)',   // 普通边框
  bdr2:    'rgba(255,255,255,0.15)',   // 强调边框（输入框focus前）
  tx:      '#f0f0f0',   // 主文字
  tx2:     '#999999',   // 次级文字（标签、说明）
  tx3:     '#555555',   // 三级文字（占位符、序号）
  ac:      '#c8f035',   // 强调色（主按钮、激活态、图表线）
  acTxt:   '#0f0f0f',   // 强调色上的文字
  blue:    '#4a9eff',
  red:     '#ff5c5c',
  orange:  '#ff9b42',
  green:   '#4ade80',
  purple:  '#a78bfa',
  pink:    '#f472b6',
}
```

### 2.2 日间模式

```ts
// tokens/colors.light.ts
export const light = {
  bg:      '#f0f0ee',
  surf:    '#ffffff',
  surf2:   '#e8e8e6',
  surf3:   '#dededc',
  bdr:     'rgba(0,0,0,0.08)',
  bdr2:    'rgba(0,0,0,0.15)',
  tx:      '#111111',
  tx2:     '#666666',
  tx3:     '#aaaaaa',
  ac:      '#4a8c00',   // 日间强调色改为深绿，确保可读性
  acTxt:   '#ffffff',   // 日间强调色上的文字必须是白色
  blue:    '#1a6fd4',
  red:     '#c93030',
  orange:  '#c06010',
  green:   '#1a9a46',
  purple:  '#6d28d9',
  pink:    '#c0306a',
}
```

> ⚠️ **关键规则**：所有用 `ac` 作背景色的按钮，文字必须用 `acTxt`，不得硬编码黑色或白色。日间/夜间 `acTxt` 不同。
