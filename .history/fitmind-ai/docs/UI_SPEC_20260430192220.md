# FitMind AI — UI 规格文档（UI_SPEC.md）

> 每次开始写前端组件前必须读这份文档。
> 颜色 token、组件结构、交互逻辑以此为准，不得自行发明。
> 原型来源：Claude Design 生成的交互式 HTML 原型（v4）。

---

## 1. 设计原则

- **风格参考**：训记 App（国内健身日志应用）—— 硬核、极简、数据驱动
- **主色调**：夜间优先，荧光黄绿（`#c8f035`）作为强调色
- **信息密度**：高密度，训练数据优先展示，减少装饰性元素
- **圆角风格**：卡片 14px，按钮 12-14px，输入框 10-12px，胶囊标签 20px
- **字体**：`-apple-system, 'PingFang SC', 'Helvetica Neue', sans-serif`
- **移动端优先**：最大宽度 390px，所有布局以竖屏手机为基准

## 4. 日志页（LogPage）

### 4.1 顶部月份切换头

```
[2026年 4月  ▼]                    [🌙]
```

- 点击月份区域 → 周条带隐藏，展开月历网格（带动画）
- 箭头图标旋转 180° 表示展开状态
- 主题切换按钮在右侧

### 4.2 周条带（WeekStrip）

- 横向滚动，7天一组
- 每个日期格：
  - 星期几（小字）
  - 日期数字（大字）
  - 训练 bar（如果当天有训练）：用 `workoutColors` 对应颜色，显示训练名称缩写
- 选中状态：`ac` 背景，文字变 `acTxt`
- 点击任意日期 → 弹出当日详情 Sheet

### 4.3 月历网格（MonthGrid）

- 7列，每格最小高度 54px
- 每格显示：日期数字 + 训练 bar（若有）
- 今日：`outline: 1.5px solid ac`
- 选中：`ac` 背景
- 其他月日期：`tx3` 颜色，不可点击
- 点击有训练的格 → 弹出当日详情

### 4.4 训练模板列表（TemplateList）

卡片式列表，每个模板：

```
● 胸 · 三头 A          4个动作   ▼
─────────────────────────────────
  平板卧推（杠铃）   复合·杠铃    4×8
  上斜哑铃卧推       复合·哑铃    3×10
  绳索夹胸           孤立·绳索    3×15
  绳索下压           孤立·绳索    3×15
─────────────────────────────────
  [编辑模板]        [▶ 用此模板开始]
```

- 点击头部行 → 展开/收起（箭头旋转动画）
- 「▶ 用此模板开始」→ 打开训练录入弹窗，并开始计时
- 「编辑模板」→ 打开模板编辑界面（可从动作库添加动作）

### 4.5 当日详情 Sheet（DayDetailSheet）

**有训练时**：
- 训练名称、时间、时长
- 3格统计：总组数 / 训练容量 / 平均 RPE
- 动作列表（含 PR 标签）
- 底部：「编辑记录」和「再练一次」按钮

**无训练时**：
- 空状态图标 + 提示文案
- 3个操作入口：
  1. ⚡ 启动力量训练（→ 打开训练录入弹窗）
  2. 📋 导入个人模板
  3. 😴 标记为休息日

## 7. 工具页（ToolsPage）

列表式入口，点击进入对应 Sheet：

| 图标 | 标题         | 副标题                   | Sheet 组件           |
|------|-------------|--------------------------|---------------------|
| ⚡   | 1RM 计算器   | 根据组数次数估算最大力量   | `RMCalculatorSheet` |
| 📏   | 身体数据记录  | 体重、围度、体脂追踪       | `BodyDataSheet`     |
| 🌸   | 经期记录     | 周期追踪与训练建议         | `PeriodSheet`       |

### 7.1 1RM 计算器（RMCalculatorSheet）

- 输入：重量(kg)、完成次数、RPE（可选）、公式选择（Epley / Brzycki / Mayhew）
- 输出：估算 1RM（大数字，`ac` 颜色）
- 训练区间参考表：100% / 95% / 90% / 85% / 80% / 75% / 70% 对应 kg 和建议次数
- 实时计算（输入变化立即更新）

**公式：**
```ts
const calcRM = (weight: number, reps: number, rpe: number, formula: string) => {
  let rm: number
  if (formula === 'epley')   rm = weight * (1 + reps / 30)
  if (formula === 'brzycki') rm = weight * (36 / (37 - reps))
  if (formula === 'mayhew')  rm = weight / (0.522 + 0.419 * Math.exp(-0.055 * reps))
  const rpeAdj = rpe < 10 ? rm / (1 - (10 - rpe) * 0.05) : rm
  return Math.round(rpeAdj)
}
```

### 7.2 身体数据记录（BodyDataSheet）

3个 Tab：体重 / 围度 / 体脂

**体重 Tab**：当前体重、目标体重统计卡 + 历史记录列表

**围度 Tab**：部位表格（部位名 + 最新值 / 上次值）
- 部位：胸围、腰围、臀围、大腿围、上臂围、小腿围

**体脂 Tab**：体脂率和目标体脂统计卡 + 分析文字

底部：「+ 记录今日数据」按钮（`ac` 背景）

### 7.3 经期记录（PeriodSheet）

- 顶部 3 格统计：平均周期天 / 平均经期天 / 当前周期第 D 天
- 月历（标记经期/易孕期/排卵日）
- 图例说明
- 今日症状标签（可多选，点击切换）
- AI 训练建议卡片（蓝色边框）
- 「记录经期开始」按钮（粉色背景 `rgba(244,114,182,0.85)`）

## 9. 训练录入弹窗（TrainSessionSheet）

从「▶ 用此模板开始」或「启动力量训练」触发，底部弹出。

### 9.1 顶部

- 左：训练名称 + 「计时中」副标题
- 右：「完成 ✓」（绿色文字）+ 「×」关闭

### 9.2 计时器条

```
组间休息      01:32      重置
```

- 计时值：`ac` 颜色，等宽字体（`font-variant-numeric: tabular-nums`）
- 打开弹窗时自动开始计时，点击任意「完成组」时重置为 0

### 9.3 动作块（ExerciseBlock）

每个动作：
- 顶部：动作名称 + 上次数据 + 「+ 加组」
- 组表格：

| # | 上次      | 重量kg | 次数 | RPE | ✓  |
|---|-----------|--------|------|-----|----|
| W | —         | 60     | 10   | —   | ✓  |
| 1 | 8×97.5    | 100    | 8    | 8.0 | ✓  |
| 2 | 8×97.5    | 100    | 7    | 8.5 | ✓  |
| 3 | 8×97.5    | 100    |      | —   | ○  |

- `W` 行为热身组
- 完成按钮（✓）点击后：背景变绿，重置计时器
- 输入框 focus 时：边框变 `ac` 颜色

### 9.4 添加动作（内嵌选择器）

点击「添加动作」→ 弹出动作选择器 Sheet（不跳转到动作库页面）。

动作选择器包含：
- 分类 Tab（全部/胸/背/腿/肩/手臂）
- 动作列表（同动作库样式）
- 每行右侧「+」按钮 → 点击变「✓」并关闭选择器，动作加入当前训练

### 9.5 底部按钮

```
[放弃训练]    [完成训练]
```

## 12. 状态管理（Zustand）

// store/chat-store.ts
interface ChatStore {
  sessions: ChatSession[]
  currentSessionId: string | null
  streamState: 'idle' | 'thinking' | 'tool_calling' | 'answering' | 'done' | 'error'
}

// store/training-store.ts
interface TrainingStore {
  selectedDate: string           // ISO 日期，决定日历选中格
  activeWorkout: WorkoutSession | null  // 进行中的训练

// store/ui-store.ts
interface UIStore {
  theme: 'dark' | 'light'
  activeTab: 'log' | 'ai' | 'lib' | 'tools' | 'data'
  openSheet: SheetType | null    // 当前打开的弹窗
}

## 13. 给 Claude Code / Codex 的使用说明

在 `AGENTS.md` 中添加以下规则：

```markdown
## 前端开发规则

1. 开始写任何前端组件前，先读 `docs/UI_SPEC.md`
2. 颜色必须使用 `tokens/colors.dark.ts` 和 `tokens/colors.light.ts` 中的变量，不得硬编码
3. 所有用 `ac` 作背景的按钮，文字必须用 `acTxt`（日间白色，夜间黑色）
4. 组件必须放在 `UI_SPEC.md` 第 11 节规定的目录结构中
5. 底部弹窗一律使用 `components/shared/Sheet.tsx` 容器
6. 动作库页面点击动作 → 打开注意事项 Sheet，不跳转页面
7. 训练录入弹窗的「添加动作」→ 打开内嵌选择器，不跳转到动作库 tab
8. 训练模板的「▶ 用此模板开始」→ 打开 TrainSessionSheet 并自动开始计时
```
